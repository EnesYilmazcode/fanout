Fanout setup

Three steps, one copyable config. Everything is created here and stored only in this browser — Fanout keeps no copy of anything on this page. Back to the demo.

1 · Get your Fanout key

Shown once. The server cannot re-show it — this browser's cache is the only copy, so download a backup at the bottom of the page when you're done.


  


  
2 · Attach your providers

  

    
Each provider key is encrypted server-side and handed straight back as a
    sealed blob that only your Fanout key can use. The plaintext key is never stored anywhere.

    

      

        
        
      

      

        
        
      

    

    
    
    

      
    

    
    
    
    
  
    

  
    3 · Copy your config
    
  
    
    
    Pick the shape your tool wants. Comma-separated connections behave as one
    pooled credential with automatic failover.
    
    
    
      
      
      
      
    
    
    
    
    
    
      
    
    
    
    If your tool only accepts a base URL and an API key, with no way to set a
    custom header, it can't attach the connection blob yet — that's a real limitation today, not
    a missing checkbox. Most OpenAI-compatible SDKs and tools do support default headers.
    
  
    

  
    Backup
    
  
    
    
    Your key and blobs live only in this browser. Lose them and the key is gone
    for good (blobs can be re-sealed from the original provider keys, the Fanout key cannot).
    The backup is a plain JSON file — treat it like the credential it is.
    
    
    
      
      
      
    
    
    
    
  
    

  
    
    Stateless by construction: keys are HMAC signatures, connections are AES-GCM blobs you hold.
    No analytics, no third-party scripts on this page — view source or read the
    code.
